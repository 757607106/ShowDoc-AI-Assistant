# 已停用的浏览器运行时

免费官方 Harness 方案不再运行本项目原有 BrowserSkill 适配。`agent/browser.py` 的 daemon 管理、配对、RPC 和工具生命周期代码已删除；ASGI 不注册旧浏览器或终端 WebSocket，也不启动其 lifespan。

旧浏览器 HTTP 控制接口返回 410。现有配对记录、偏好、容器与用户文件保留，不在部署或打开历史页面时撤销、清理或重新连接。保存的浏览器偏好不代表当前可以执行浏览器操作。

原目录中的验证产物属于旧方案历史证据，不能作为本次实现的浏览器能力或验收依据。当前可用能力和启动方式见 [Agent 运行组件](agent-runtime-backends.md)。项目的独立网页采集业务不受本次 Agent 浏览器停用影响。
